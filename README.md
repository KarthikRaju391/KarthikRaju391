# Karthik S Raju

Software generalist building developer tools, agent workflows, and thoughtful products.

I care about systems that reduce friction without hiding how they work. Outside code, I ride motorcycles and write about technology, work, and agency.

## Selected work

- [docent.nvim](https://github.com/KarthikRaju391/docent.nvim) — MCP-powered guided code tours in Neovim, with nested navigation and headless integration tests.
- [Pi Zellij Tools](https://github.com/KarthikRaju391/pi-zellij-tools) — Background-task orchestration for Pi and Zellij, with persistent task state, completion events, and a task dashboard.
- [Agent Solution Protocol](https://github.com/KarthikRaju391/agent-solution-protocol) — A structured protocol, CLI, and registry for sharing agent debugging solutions, with sanitization tests and smoke fixtures.
- [Pi Account Pool](https://github.com/KarthikRaju391/pi-account-pool) — Account-profile pooling for Pi, with cooldown-aware selection and sandboxed launch-behavior tests.
- [Go NATS Chat Server](https://github.com/KarthikRaju391/go-nats-chat-server) — A Go WebSocket chat server built with NATS JetStream, preserved as a backend architecture example with unit tests.
- [Floating Highlights](https://github.com/KarthikRaju391/obsidian-float) — An Obsidian plugin for floating reading and highlighting workflows.

### More explorations
